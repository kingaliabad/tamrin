# همراه تمرین من – اپ اندروید

برنامه وب شما داخل یک پوسته اندروید (WebView) قرار گرفته و با GitHub Actions به APK امضاشده تبدیل می‌شود.

---
## راهنمای کامل از صفر تا APK

### ۱) ساخت حساب و مخزن در GitHub
1. در github.com ثبت‌نام کنید (اگر حساب ندارید).
2. بالا سمت راست **+** ← **New repository**.
3. نام مثلاً `hamrah-tamrin`، گزینه **Private**، و **هیچ‌کدام** از تیک‌های README / .gitignore / license را نزنید. ← **Create repository**.

### ۲) نصب Git
- ویندوز: از git-scm.com نصب کنید (همه گزینه‌ها پیش‌فرض).
- مک: در ترمینال `xcode-select --install`
- لینوکس: `sudo apt install git`

### ۳) تنظیم هویت (فقط بار اول)
```
git config --global user.name "نام شما"
git config --global user.email "ایمیل-حساب-گیتهاب"
```

### ۴) باز کردن پروژه و آپلود
فایل zip را Extract کنید. داخل پوشه `hamrah-tamrin-android` ترمینال (ویندوز: Git Bash) را باز کنید:
```
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/USERNAME/hamrah-tamrin.git
git push -u origin main
```
به‌جای `USERNAME` نام کاربری GitHub خودتان را بگذارید.

### ۵) ورود (Authentication)
GitHub رمز عبور حساب را قبول نمی‌کند. هنگام `git push`:
- ویندوز/مک معمولاً یک پنجره مرورگر باز می‌شود؛ وارد شوید.
- اگر Username/Password خواست: Username = نام کاربری، Password = **Personal Access Token**.
  ساخت توکن: GitHub ← Settings ← Developer settings ← Personal access tokens ← Tokens (classic) ← Generate new token، تیک **repo** و **workflow** را بزنید و توکن را کپی کنید.

### ۶) اجرای بیلد
- با اولین push بیلد خودکار شروع می‌شود. تب **Actions** ← بیلد «Build APK».
- اگر شروع نشد: Actions ← **Build APK** ← **Run workflow**.
- بعد از ۳ تا ۵ دقیقه علامت سبز می‌شود. اگر قرمز شد، روی بیلد بزنید، مرحله خطادار را باز کنید و متن خطا را برای من بفرستید.

### ۷) دانلود APK
- مخزن ← سمت راست **Releases** ← آخرین نسخه ← `hamrah-tamrin.apk`
- یا داخل صفحه همان بیلد ← **Artifacts** ← `hamrah-tamrin-apk` (zip است، باز کنید).

### ۸) نصب روی گوشی
فایل را به گوشی منتقل کنید و باز کنید. اگر پرسید، «نصب از منابع ناشناس» را برای همان برنامه (مرورگر یا فایل‌منیجر) مجاز کنید. حداقل اندروید ۱۰.

### ۹) تغییرات بعدی
بعد از هر تغییر در فایل‌ها:
```
git add .
git commit -m "توضیح تغییر"
git push
```
بیلد جدید خودکار ساخته می‌شود و روی نسخه قبلی نصب می‌شود (اطلاعات حفظ می‌شود).

## قابلیت‌ها
- یادآور دارو با آلارم بومی: هر روز سر ساعت، حتی وقتی برنامه بسته است؛ بعد از ریبوت هم برقرار می‌ماند.
- اگر همان روز «ثبت مصرف» بزنید، اعلان آن روز نمی‌آید.
- پشتیبان‌گیری JSON در پوشه Downloads و بازیابی از فایل.
- نمودار روند وزن، حذف سوابق و علائم.
- برنامه مجوز اینترنت ندارد؛ داده‌ها فقط روی گوشی می‌مانند.

## نکات
- **کلید امضا:** `app/keystore/hamrah.jks` برای نصب بیلدهای بعدی روی قبلی داخل مخزن است. مخزن را عمومی نکنید، یا کلید خودتان را بسازید و رمزها را در `app/build.gradle` عوض کنید.
- **آیکون ساعت** در نوار وضعیت به‌خاطر روش آلارم نمایش داده می‌شود.
- **شیائومی/سامسونگ/اوپو و …:** اگر اعلان نیامد، Battery optimization را روی Unrestricted و Autostart را روشن کنید.
- بعد از نصب «آزمایش اعلان» را بزنید و یک یادآور ۲ دقیقه بعد تست کنید.
- داده‌های نسخه PWA منتقل نمی‌شوند؛ از آن پشتیبان بگیرید و در اپ جدید بازیابی کنید.
